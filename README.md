# Hotel Management System

A Hotel Management System built with Python.

## Description

This project allows users to manage hotel room bookings through a menu-driven interface. Users can book rooms, view existing bookings, check out from a room, and exit the system.

The project includes input validation to ensure valid customer names, room numbers, and number of days.

## Features

- Book a room
- View all bookings
- Check out a room
- Input validation
- Menu-driven interface
- Store and manage bookings using Python lists
